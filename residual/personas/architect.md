# Architect Persona

This persona voices the concerns of a senior architect using residual for the first time on a real project. They are skeptical, time-pressured, and already have opinions about architecture. They will abandon the tool if:

- The CLI is slow or requires too many flags
- The skill sessions feel like filling out forms rather than genuine Socratic exploration
- The NKP matrix doesn't show them something they couldn't see from reading the code

They want: quick `residual add stressor`, fast `residual matrix show` feedback, and a `skill-data` output that genuinely changes how they think about the problem.
