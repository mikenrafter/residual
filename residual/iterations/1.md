# Iteration 1 — Naive Architecture

## Architecture

Vertical slice by CLI command group. Each command group owns its domain:

- `storage/` — CSV + markdown CRUD for all residual data types
- `nkp/` — matrix construction, Ri calculation, criticality assessment
- `skills/` — embedded definitions, install path resolution, context building
- `verify/` — trait validation, referential integrity
- `tags/` — codebase annotation scanning

No shared service layer. Commands dispatch directly to module functions. Configuration loaded once from `residual/config.toml` at startup.

## Residues Identified

- **R-01** (S-01): Version checking — skills need front-matter version field; `skill-check` reads installed file, compares to embedded version
- **R-02** (S-04): Idempotent init — `init` must check before writing; never overwrite existing data
- **R-03** (S-05): Token warning — `skill-list` and `skill-show` should warn when estimate_tokens() > token_warn config

## Open Questions

- File locking for concurrent CSV writes (S-03) deferred — not in v0.1 scope
- P value tracking (qualitative measure of interface discipline) has no CLI representation yet
- Research::save() implemented but not exposed in any CLI command — needs `residual research save <source>` command or agent instruction
